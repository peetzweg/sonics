Initial release. `sonics` synthesises tasteful, dependency-free UI microinteraction sounds in the browser with the Web Audio API — no audio files. Ships a small set of presets (click, tap, tick, pop, toggle on/off, success, error), a serialisable sound spec with `encode`/`decode`, WAV export, and React bindings (`sonics/react`). `web-sonics` and `web-sfx` are thin aliases that re-export `sonics`.
